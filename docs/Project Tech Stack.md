# Project Tech Stack
VS Code extension for AI-powered code understanding and navigation.

## Environment Requirements

### Node.js
- **Recommended Version**: Node.js 18.x or 20.x (LTS)
- **Minimum Version**: Node.js 18.0.0
- **Installation**: Download from https://nodejs.org/ (use LTS version)

### Package Manager
- **Primary**: npm (version 9.x or higher)

### Verification Commands (Windows PowerShell)
```powershell
node -v  # Should show v18.x.x or v20.x.x
npm -v   # Should show 9.x.x or higher
npx -v   # Should show 9.x.x or higher
