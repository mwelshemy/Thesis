# VS Code Mock UI (Phase 2–3 – Day 1–2)
This is the mock UI shell for the AI Code Retrieval prototype, built as a VS Code extension.

## Features
- Opens a sidebar panel like GitHub Copilot
- User can enter a query and click "Run"
- Displays mock retrieval + AI analysis output

## Run Locally
1. Open VS Code → press F5 (Run Extension)
2. Open command palette → `Open AI Assistant Panel`
3. Type a query (e.g., "Explain connect function")
4. View the simulated output
