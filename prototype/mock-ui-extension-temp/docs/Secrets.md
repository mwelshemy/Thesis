# Security & API Keys Management

## Local Development

### 1. Get Hugging Face Token

1. Go to [Hugging Face Settings](https://huggingface.co/settings/tokens)
2. Create a new token (free tier available)
3. Copy the token

### 2. Local Setup

```bash
# Copy the example file
cp .env.example .env

# Add your actual token to .env
# .env is already in .gitignore for security
```
