About This Project

Code Retrieving Using AI is a thesis project built to demonstrate the power of artificial intelligence in handling code-centric tasks. This AI system is specifically designed for three major functionalities:

  1. Code Conversion: Seamlessly convert code from one programming language to another. Whether you're moving from Python to JavaScript, Java to C#, or any other supported languages, the AI understands the logic and syntax nuances to generate accurate conversions.
  2. Code Retrieving: Upload your codebase or individual files, and then interact with the AI to search for specific parts, functions, or logic within your code. Just describe what you're looking for, and the AI will pinpoint the relevant code sections for you.
  3. Code Improvement (Optional): After retrieving code, you may choose to ask the AI for suggestions on how to improve it. The system can recommend optimizations, refactoring, or enhancements for readability, performance, and maintainability.

How It Works

  • Upload your code or paste snippets into the interface.
  • Ask questions in natural language to retrieve or convert code.
  • Optionally request AI-powered improvements or suggestions for your code.
  • Interact via a chat-inspired UI, with support for dark mode and customizable settings.
