# VS Code AI Assistant

A powerful AI-powered code understanding and analysis extension for VS Code that helps you understand, navigate, and improve your codebase.

![VS AI Assistant](resources/icon.png)

## Features

###  AI-Powered Code Analysis
- **Smart Code Explanation**: Get detailed explanations of any code selection
- **Bug Detection**: Identify potential issues and security vulnerabilities
- **Improvement Suggestions**: Receive actionable code improvement recommendations
- **File Summarization**: Quick overviews of complex files

###  Intelligent Search
- **Semantic Search**: Find code by meaning, not just keywords
- **Project-wide Search**: Search across your entire codebase
- **Language Filtering**: Filter results by programming language
- **Real-time Indexing**: Automatic updates as you work

###  Interactive Chat Interface
- **Context-Aware Chat**: Ask questions about your specific code
- **Project Context**: AI understands your project structure
- **Multi-turn Conversations**: Maintain context across questions

## Quick Start

1. **Install the extension** from VS Code Marketplace
2. **Open the AI Assistant**:
   - Click the AI icon in the activity bar, or
   - Use `Ctrl+Shift+P` and search for "Show AI Assistant"
3. **Start using AI features**:
   - Use the chat interface to ask questions
   - Run project analysis from the Analyze tab
   - Search your codebase from the Search tab
